Site statique (un seul fichier `index.html`), sans backend.

## Déployer sur Vercel
1. Crée un dépôt GitHub et pousse ce dossier.
2. Sur vercel.com : Add New → Project → importe le dépôt.
3. Framework preset : **Other**. Aucune commande de build, aucun dossier de sortie à régler. Deploy.

Alternative sans GitHub : `npx vercel` dans ce dossier.
